# Capturing portfolio screenshots

Take screenshots from the actual application after `python gui.py` opens successfully. Do not use a mockup as proof that the code runs.

## Screenshot 1 — Main interface

1. Open the app and maximize or size it so the sidebar and chat area are visible.
2. Use a clean window with no error dialogs or unrelated apps in front.
3. Capture the window using **Win + Shift + S** on Windows.
4. Save the image as `assets/voice-assistant-gui.png`.

## Screenshot 2 — Working conversation

1. Start listening.
2. Ask: `Explain Java classes and objects in simple terms.`
3. Wait until the answer appears in the conversation history.
4. Capture the completed exchange and save it as `assets/voice-assistant-conversation.png`.

## Optional third screenshot — Terminal / architecture

Capture a terminal showing a successful `ollama list` or the app starting without errors, but make sure no private paths or sensitive information are visible. Save it as `assets/voice-assistant-terminal.png`.

## Before committing

- Crop out personal notifications and unrelated desktop content.
- Make sure text is readable at GitHub's image display size.
- Check the images do not reveal secrets, private conversations, or personal data.
- Confirm both README image links work when previewing `README.md`.
